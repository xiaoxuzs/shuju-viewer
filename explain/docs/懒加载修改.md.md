## `docs/懒加载修改.md` 逐行解释

> 该文档是一次“懒加载（lazy-load）策略”改造的记录/说明：核心思想是把 PrSM 详情与谱图大对象从“导入时全量入库/全量解析”改为“列表只存摘要 + detail_path，详情打开时按需从磁盘读取”。这与当前仓库的 fast 模式导入、`load_prsm_detail`、`SpectrumCache`、以及 mzML-memory 的 lazy-load 是同一类设计取向。

本文件内容以“描述改动点与原因”为主（不像 schema 文件那样是 DDL）。逐行解释的重点是：每个改动点对应代码库的哪个模块、最终形成了什么读写行为。
