# 性能测验约定（指纹阶段）

## 目标

- 在**已解析的数据集 ingest 根目录**上执行指纹模块（元数据 manifest MD5，语义同 `MD5-demo/fast_metadata_hash.py`）。
- **墙钟时间 ≤ 0.5 秒**（以本机多次测量取中位数为准；首次实施若超标，需在 MR/说明中记录 profiling 结论后再调优）。

## 基准数据集

- 名称：**`MZ20160222DS_histone49_html`**
- 路径：在 **`cs/指纹性能测验.py`** 文件顶部修改常量 **`BENCHMARK_DATASET_PATH`**（推荐）；也可通过环境变量 **`VIEWER_BENCH_DATASET_ROOT`** 覆盖（便于 CI）。路径可为外层嵌套目录，脚本会先 **`resolve_ingest_root`** 再测指纹。

## 建议输出

每次正式跑性能验收时至少输出：

1. 解析后的根路径（字符串）
2. 文件数量 `file_count`
3. 指纹 hex
4. 至少 3 次耗时的 **中位数**（秒）

## 与 `back/tests/` 的关系

- **正确性**（排序、排除规则、mtime/size 变化导致指纹变化）：优先用 `back/tests/` 中小 fixture + pytest。
- **性能与真实数据规模**：在本目录用中文命名的入口脚本或说明执行；CI 可选跳过或仅在带环境变量的 job 中运行。

## 推荐命令

在仓库根目录 `viewer` 下，先编辑 ``cs/指纹性能测验.py`` 里的 ``BENCHMARK_DATASET_PATH``，然后::

    python cs\指纹性能测验.py

或::

    uv run --directory back python ..\cs\指纹性能测验.py

（若设置了 ``VIEWER_BENCH_DATASET_ROOT``，会覆盖文件内常量。）

脚本会先 ``resolve_ingest_root`` 再测指纹；耗时上限由同文件内 ``TIME_BUDGET_SECONDS`` 控制（默认 0.5s），未达标时进程退出码为 1。
