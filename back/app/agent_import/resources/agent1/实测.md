**观测：**

- `mqpar.xml` 记录 `maxQuantVersion=2.8.1.0`。
- 实验及结果的 run 名均为 `pxd000001`。

**结论：**这是一个 MaxQuant 肽段鉴定及蛋白组结果数据包，配有参考 FASTA、RAW 及既有 RAW 转换产物。结果结构、酶切配置和 `Standard` run 类型与 bottom-up、DDA shotgun 数据解释一致。[E2–E7、E9]

### 4.3 必须保留的特殊情况

**蛋白组 6 不是两个独立定量结果。**

`Protein IDs=ECA4035;ECA0216`，两者都能在 FASTA 中找到，肽段 `IIELAGYLDSYIPEPER` 在两条序列中的位置均为 189–205。来源组强度为 `342860000`，不能将这个值分别赋给两个成员后再相加。[E3、E8]

**标识不能混用。**

本数据 mzML 中 `index=scan−1` 经全量检查成立，但这只是当前文件的观测。evidence 中 `Scan index*` 全为零；`MS/MS IDs` 是另一张来源表的内部引用，不能用作 RAW scan number。[E2、E7、E8]

**质荷比存在不同角色。**

全部 35 条 evidence 的 `MS/MS m/z` 与 mzML isolation target 的最大绝对差为约 `2.50×10⁻¹²`。但在 evidence 5、7、30 对应谱图中，selected-ion m/z 与 isolation target 不同，因此两字段必须分别保存。[E8]

**电荷不同不应自动判定为错误关联。**

以下 evidence 的来源鉴定电荷与 mzML 采集电荷不同：

| Evidence ID | 鉴定 `Charge` | mzML selected-ion charge |
|---|---:|---:|
| 0 | 2 | 3 |
| 3 | 7 | 2 |
| 14 | 3 | 2 |
| 19 | 6 | 2 |
| 20 | 6 | 2 |
| 22 | 4 | 2 |
| 24 | 3 | 2 |
| 34 | 5 | 3 |

这些记录仍通过 scan 和 isolation target 核对。不能用采集电荷覆盖鉴定电荷，也不能据此修改鉴定结果。
