# 文件判别模块 — 实施规划

**状态**：§1–§7 已实现；§9 第 1–5 步完成（PFMB adapt 占位）  
**日期**：2026-05-28  
**范围**：viewer-TD TopPIC Top-Down 路径导入 — **只回答「这是什么数据、走哪条路」**  
**原则**：低耦合、高模块化（对齐仓库 `AGENTS.md`）

---

## 1. 模块要回答的问题

用户选择一个目录后，在指纹 / PFMB / 入库之前，判别层只输出**结构化结论**：

| 问题 | 判别结果示例 |
|------|----------------|
| ingest 根在哪？ | `ingest_root: Path`（委托现有根解析） |
| 是否已有 viewer 解释文件？ | 是 → **形态 A**，直接入库 |
| 是否是 TopPIC 流水线包（无 `data/`）？ | 是 → **形态 B**，走 PFMB 适配 |
| 形态 B 的 xml / msalign / mzML 如何配对？ | 一组或多组 `RunTriple` |
| 为什么不支持？ | `AdmissionReject` + 可读原因 |

**不做**：指纹、PFMB 子进程、JSON 组装、写 DB（均在其它模块 / 薄编排）。

## 3. 判别结果（对外契约）

建议包路径：`back/app/toppic_admission/`

### 3.1 枚举

```python
class AdmissionRoute(str, Enum):
    DIRECT_INGEST = "direct_ingest"   # 形态 A：已有解释文件
    NEED_PFMB     = "need_pfmb"       # 形态 B：流水线包，需适配
    UNSUPPORTED   = "unsupported"     # 拒绝导入

class DirectIngestShape(str, Enum):
    TOPPIC_HTML   = "toppic_html"     # A1/A2
    PRSM_BUNDLE   = "prsm_bundle"     # A3

class PfmbIngestSource(str, Enum):
    XML_MSALIGN = "xml_msalign"       # 330 类（xzx_PXD045330）
    TOPPIC_JS   = "toppic_js"         # histone 类（预留，本阶段可不触发 run）
```

### 3.2 核心数据结构（纯 dataclass，无 I/O）

```python
@dataclass(frozen=True)
class RunTriple:
    """形态 B：一次 run 的 PFMB ingest 输入。"""
    prsm_xml: Path
    ms2_msalign: Path
    mzml: Path
    run_key: str          # 用于日志 / staging 子目录名（basename 规则导出）

@dataclass(frozen=True)
class AdmissionEvidence:
    """可写入 job 日志 / 前端 detail 的只读证据。"""
    has_topfd: bool
    has_toppic_dir: bool
    has_prsm_xml: bool
    has_ms2_msalign: bool
    has_mzml: bool
    prsm_file_count: int
    is_toppic_html_tree: bool
    notes: tuple[str, ...]

@dataclass(frozen=True)
class AdmissionDecision:
    route: AdmissionRoute
    ingest_root: Path
    evidence: AdmissionEvidence
    # 以下互斥填充
    direct_shape: DirectIngestShape | None = None
    pfmb_source: PfmbIngestSource | None = None
    run_triples: tuple[RunTriple, ...] = ()
    reject_reason: str | None = None
    reject_code: str | None = None   # 稳定机器码，如 "missing_ms2_msalign"
```

### 3.3 公开 API（窄接口）

```python
# back/app/toppic_admission/__init__.py

def classify_admission(ingest_root: Path) -> AdmissionDecision:
    """对已解析的 ingest 根做 TopPIC 文件判别（只读）。"""

def classify_user_path(user_selected: Path | str) -> AdmissionDecision:
    """resolve_ingest_root + classify_admission；根解析失败抛 ValueError。"""
```

**禁止**对外暴露内部 `signals` / `pairing` 细节；测试可 import 子模块。

## 4. 包内模块划分

```text
back/app/toppic_admission/
  __init__.py          # 公开 API：classify_admission, classify_user_path
  types.py             # AdmissionRoute, AdmissionDecision, RunTriple, …
  errors.py            # AdmissionReject（可选，或直接用 Decision.reject_*）
  signals.py           # 只读探针：collect_signals(root) -> SignalSnapshot
  classify.py          # 决策树：signals -> AdmissionDecision
  pairing.py           # xml/msalign/mzML 配对（形态 B）
```

### 4.1 `signals.py` — Filesystem 探针（只读）

**职责**：一次遍历 / 少量 `rglob`，收集事实，**不做业务结论**。

| 探针 | 实现建议 |
|------|----------|
| `has_supported_prsm_files` | 调用 `prsm_files.ingest_root_has_supported_prsm_files` |
| `is_toppic_html_tree` | 调用 `import_planner.detectors.is_toppic_html_tree` |
| `prsm_bundle_dir` | 调用 `prsm_files.prsm_bundle_prsm_directory` |
| `topfd_dir_exists` | `(root / "topfd").is_dir()` |
| `toppic_dir_exists` | `(root / "toppic").is_dir()` |
| `glob_prsm_xml` | `list(root.glob("toppic/**/*_toppic_prsm.xml"))` 等 |
| `glob_ms2_msalign` | `list(root.glob("topfd/**/*_ms2.msalign"))` |
| `glob_mzml` | 复用 `mzml_mapping.collect_mzml_files` 或等价 |
| `bu_layout` | 调用 `has_bu_diann_layout`（用于**明确拒绝**） |

输出：`SignalSnapshot`（dataclass，字段与 `AdmissionEvidence` 对齐）。

**禁止**：依赖 FastAPI、SQLAlchemy、PFMB、指纹。

### 4.2 `pairing.py` — Run 配对（形态 B）

**职责**：从 signals 中的路径列表，产出 `RunTriple` 或配对错误。

**v1 规则**（xzx_PXD045330 实测）：

1. 文件名共享 run 前缀，例如  
   `{prefix}_ms2_toppic_prsm.xml` ↔ `{prefix}_ms2.msalign` ↔ `{prefix}.mzML`
2. 去掉固定后缀再匹配：
   - xml：`*_toppic_prsm.xml` 或 `*_ms2_toppic_prsm.xml`
   - msalign：`*_ms2.msalign`
   - mzml：`* .mzML`（basename，不含目录）
3. **单 run 数据集**：恰好 1 组 triple → 通过  
4. **多 run**：每组 triple 独立；任一条 xml 无 msalign / 无 mzml → `reject_code=unpaired_run`  
5. 多个 xml 对同一 msalign → `reject_code=ambiguous_pairing`

**禁止**：读 xml/msalign 内容（配对仅看路径；内容校验留给 PFMB ingest）。

### 4.3 `classify.py` — 决策树

```text
collect_signals(ingest_root)
  ↓
若 bu_layout → UNSUPPORTED (viewer-TD 不做 BU)

若 has_supported_prsm_files:
  若 is_toppic_html_tree → DIRECT_INGEST / TOPPIC_HTML
  若 prsm_bundle_dir     → DIRECT_INGEST / PRSM_BUNDLE
  否则 → UNSUPPORTED (有 prsm 但 layout 无法映射) 或 NEED_PFMB（待定 §8）

否则若 topfd + toppic + prsm_xml + ms2_msalign + mzml:
  pairing → run_triples
  若 triples 非空 → NEED_PFMB / XML_MSALIGN
  否则 → UNSUPPORTED (pairing 失败)

否则若 仅 mzml → UNSUPPORTED (missing_toppic_pipeline)

否则 → UNSUPPORTED (unknown_layout)
```

**优先级**：**解释文件优先** — 有 `prsm*` 一律形态 A，不进入 PFMB。

### 4.4 与 `import_planner` 的分工

| 阶段 | 模块 | 输入目录 |
|------|------|----------|
| 判别后、形态 A | `plan_zip_ingest(ingest_root)` | 用户原目录 |
| PFMB adapt 完成后 | `plan_zip_ingest(staging_root)` | staging（含 `data/prsms/*.json`） |

`import_planner` **不修改**决策树；形态 B 在 adapt 前调用 `plan_zip_ingest` 本来就会失败 — 这是预期，由 `import_jobs` 先看 `AdmissionDecision.route`。

## 5. 需动到的现有模块（最小 diff）

### 5.1 `dataset_ingest_root/resolver.py`

**问题**：形态 B 无 `data/`，但有 `topfd/`，已能 `resolve_ingest_root`；若只有 `toppic/`+`mzML` 可能失败。

**建议**：新增窄函数，供 resolver 与 admission 共用：

```python
def has_toppic_pipeline_layout(path: Path) -> bool:
    """topfd/ + toppic/ + 至少一个 *_toppic_prsm.xml + mzML（不要求 data/）。"""
```

`_matching_layouts` 扩展：

- TD 阶段：`TopPIC` 匹配 = `has_dataset_layout` **或** `has_toppic_pipeline_layout`
- **仍拒绝** `has_bu_diann_layout`（或匹配但 admission 层 UNSUPPORTED）

**不在 resolver 里**区分 A/B — 只保证「找得到根」。

### 5.2 `api/v1/imports.py` enqueue

`resolve_ingest_root` 之后增加 **快速判别**（可选）：

- `UNSUPPORTED` → HTTP 400，`detail=reject_reason`
- `NEED_PFMB` / `DIRECT_INGEST` → 允许入队（job 内再 discriminant）

避免 worker 跑到一半才失败；**不在 API 层**跑 PFMB。

### 5.3 `import_jobs.run_path_import_job`

伪代码：

```python
decision = classify_admission(ingest_root)
if decision.route == UNSUPPORTED:
    raise RuntimeError(decision.reject_reason)
if decision.route == NEED_PFMB:
    ingest_root = run_adapt_pfmb(decision)  # 后续模块
# DIRECT_INGEST: ingest_root 不变
fp = fingerprint(ingest_root)
plan = plan_zip_ingest(ingest_root)
...
```

## 6. 低耦合检查清单

| 规则 | 说明 |
|------|------|
| 判别模块零 DB | 不 import SQLAlchemy / `import_jobs` |
| 判别模块零 PFMB | 不 spawn 子进程 |
| 判别模块零指纹 | 不递归 MD5 |
| 复用不复制 | prsm 后缀、TopPIC html、mzML 收集用现有函数 |
| 纯函数优先 | `classify(signals)` 可单测，不碰磁盘时可 inject `SignalSnapshot` |
| 稳定 reject_code | 前端 / 日志 i18n 可映射 |
| 编排保持薄 | `import_jobs` 不超过数十行分支 |

## 10. 总结

- **新包 `toppic_admission`** 专做文件判别；输出 `AdmissionDecision`。
- **形态 A / B** 由「有无解释文件」+「流水线信号」决定；B 的 xml/msalign/mzML 配对独立在 `pairing.py`。
- **现有模块**只做最小扩展；plan / fingerprint / PFMB / ingest **不并入判别包**。
- **测试**以 pytest + tmp_path 为主；PFMB exe 验收保持独立。

确认 §8 待定项后，可按 §9 开始编码第 1 步。
