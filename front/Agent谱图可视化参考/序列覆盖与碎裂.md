# 序列覆盖与碎裂

## 1. TD 序列视图

组件：[`SequenceView`](../src/features/prsm/SequenceView.tsx)。

- 输入：`AnnotatedProtein`，来自 [`parseAnnotatedProtein`](../src/features/prsm/parse.ts)。
- 使用单个 React SVG 还原 TopMSV 的固定几何。
- 每行 30 个残基、每 10 个残基一组；包含位置编号、break-point bracket、mass shift 背景和注释。
- 支持 N/C 端跳过提示和 cleavage 点击回调。
- 颜色来自 `CHART_COLORS` 与 ion CSS token。

## 2. TD 碎裂梯图

组件：[`FragmentationView`](../src/features/prsm/FragmentationView.tsx)。

它把三部分放在同一 monoisotopic mass X 轴：

1. N/C 端离子序列梯图。
2. 去卷积峰 stick plot。
3. 匹配离子的 ppm error plot。

理论质量来自组件内的单同位素残基质量表，并结合 `AnnotatedProtein.massShifts`。显示密度由 px/Da 控制，浏览方式是原生水平滚动，不是 spectrum brush zoom。

## 3. BU 蛋白序列覆盖

```text
BuProteinDetailPage
└─ SequenceCoverage
   ├─ coverageLayout
   ├─ coverageColors
   ├─ PeptideLegend
   └─ CoverageBar（每个 sequence row）
```

[`SequenceCoverage`](../src/features/bu/components/sequence/SequenceCoverage.tsx) 输入 `BuProteinDetailOut`，支持四种覆盖模式：`full`、`partial`、`list_only`、`decoy`。

[`coverageLayout.ts`](../src/features/bu/components/sequence/coverageLayout.ts) 负责：

- 序列分行。
- 后端覆盖片段映射到残基坐标。
- 稳定的肽段选择 key 和颜色表。
- 图例生成。
- 残基/片段颜色、tooltip 文案。

[`coverageColors.ts`](../src/features/bu/components/sequence/coverageColors.ts) 统一肽段色板和选中高亮。不要在 `CoverageBar` 中重新分配颜色，否则图例和残基会失配。

主要测试：[`bu-protein-sequence-coverage.spec.ts`](../tests/bu-protein-sequence-coverage.spec.ts)，覆盖 full、partial、list-only、decoy 和选择行为。

## 4. PFMB 序列覆盖

组件：[`BuSequenceCoverage`](../src/features/bu/components/match-detail/BuSequenceCoverage.tsx)。

- 输入是 peptide 和 `BuMs2AnnotationOut.matched_ions`。
- 使用 [`pfmbSeries.ts`](../src/features/bu/components/match-detail/pfmbSeries.ts) 把 b/y/c/z· 转成切割位点。
- 与 `BuPfmbHeatmap` 共享 fragment family 高亮。
- 颜色必须与 PFMB heatmap、碎片表和 live spectrum external annotation 一致。

## 5. 碎片表与图形的关系

| 表格 | 数据来源 | 与图形的联动 |
|---|---|---|
| [`MatchedPeaksTable`](../src/features/prsm/MatchedPeaksTable.tsx) | TD `MsPeakRow[]` | 选择后打开 `MatchedPeakSpectrumPanel` |
| [`BuFragmentTable`](../src/features/bu/components/match-detail/BuFragmentTable.tsx) | live `BuMatchedIon[]` | 选择/取消产物离子 XIC |
| [`BuPfmbFragmentTable`](../src/features/bu/components/match-detail/BuPfmbFragmentTable.tsx) | PFMB `BuMs2FragmentRow[]` | 与 heatmap/coverage 共享 family 高亮；保持 neutral mass 语义 |

PFMB 表格不能被改成 live mzML 表格的字段语义；二者数据来源和质量单位不同。
