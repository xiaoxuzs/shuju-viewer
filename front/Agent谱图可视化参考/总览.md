# Agent 谱图可视化参考

## 目的

本目录是给 Agent 使用的谱图可视化索引，不是运行时组件包，也不是第二份前端源码。

- 生产实现的唯一事实来源仍是 [`front/src`](../src/)。
- 本目录只保存分类、职责、数据契约、测试依据和源码链接。
- 生产代码不得从本目录导入任何内容。
- 更新组件时应修改原源码，再同步这里的索引；不要把 TSX 复制到本目录维护。

## 当前结论

盘点日期：2026-08-31。

- 前端工程使用 D3 `7.9.0` 和 Three.js `0.184.0`，依赖声明见 [`package.json`](../package.json)。
- 从 [`main.tsx`](../src/main.tsx) 开始静态追踪，共到达 132 个前端源码文件。
- 当前四个可视化业务区 `bu`、`prsm`、`lcms3d`、`spectra-only` 共 91 个 TypeScript/TSX 文件，其中 88 个可达。
- 当前业务区只有 3 个不可达文件：`BuPfmbSpectrumChart.tsx`、`chartUtils.ts`、`BuComingSoonPage.tsx`。
- [`features/bu-viewer`](../src/features/bu-viewer/) 有 67 个文件，但外部引用为 0，是历史副本，不是当前实现。
- 发现 11 个当前可达的直接图形渲染器，以及 1 个未启用的直接渲染器；详情见[完整组件目录](./完整组件目录.md)。
- `front` 根目录有 20 张历史 PR/调试截图；它们可帮助理解界面，但不能证明当前代码行为。

## 可视化范围

本参考目录覆盖以下内容：

1. TD 原始/匹配质谱、局部包络、序列视图和碎裂梯图。
2. BU MS1/MS2、实时离子注释、PFMB 外部注释和产物离子选择。
3. TIC、BPC、前体同位素 XIC、产物离子 XIC。
4. RT-m/z 热图、PFMB RT×碎片热图、DIA 窗口图、m/z×离子迁移率散点图。
5. BU 蛋白序列覆盖、PFMB 序列覆盖和碎片表。
6. 纯谱图数据集的扫描列表、亲子扫描关系、峰标签和原始峰表。
7. 单扫描 Three.js 三维谱图。
8. 图表主题、缩放、模态框、首帧通知、空/错误/派生数据状态。
9. 可视化使用的前端类型、API 客户端、后端路由和测试。

普通数据列表、导入页面、按钮/卡片等通用 UI 不作为谱图可视化组件收录；如果它们直接参与可视化编排或状态展示，则作为“编排/支撑组件”登记。

## 状态定义

- `当前使用`：可从 `main.tsx` 沿静态导入到达，并在当前路由或其子组件中使用。
- `间接支撑`：不直接绘图，但为数据、标注、交互、主题或状态提供必要能力。
- `未启用`：位于当前源码区，但静态导入不可达或没有消费者。
- `历史副本`：已被当前实现替代，不应作为新增工作的基础。

## 使用原则

Agent 在新增或修改谱图展示前，应先找到最接近的当前组件和数据契约。优先复用现有渲染器、颜色和状态模型；不得从 `bu-viewer` 复制实现，也不得根据历史截图反推当前接口。
