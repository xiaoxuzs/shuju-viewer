# 谱图与峰标注

## 1. 三条当前生产路径

### TD PrSM

```text
PrsmDetailPage
├─ fetchPrsm / fetchMs1Spectrum / fetchMs2Spectrum / fetchMzmlSpectrum
├─ parse.ts
│  ├─ parseAnnotatedProtein
│  ├─ parseMsPeaks
│  ├─ parseRawSpectrum
│  └─ findMatchedEnvelope
├─ SequenceView
├─ SpectrumChart（MS1 / MS2）
├─ MatchedPeaksTable → MatchedPeakSpectrumPanel → SpectrumChart
├─ FragmentationView
└─ Lcms3DPanel
```

入口：[`PrsmDetailPage.tsx`](../src/pages/PrsmDetailPage.tsx)。解析模型：[`parse.ts`](../src/features/prsm/parse.ts)。

[`SpectrumChart`](../src/features/prsm/SpectrumChart.tsx) 是 TD 和纯谱图共享的通用 stick-spectrum 渲染器。主要能力：

- D3 比例尺、坐标轴、brush X 缩放和 Y 缩放。
- 受控或内部 `Zoom`；大图可由父组件保存缩放状态。
- MS1 precursor marker、m/z guide、包络 hollow-circle overlay。
- 原始峰标签、单峰选择、点击回调。
- 绝对强度、全谱 base-peak 百分比，以及局部 `yPercentBase` 百分比。
- 可见区峰过多时按像素桶 max-pooling；匹配离子始终保留。
- `onFirstRender` 用于页面切换遮罩的首帧协调。

[`MatchedPeakSpectrumPanel`](../src/features/prsm/MatchedPeakSpectrumPanel.tsx) 为一个去卷积匹配峰查找 TopFD envelope，按同位素簇建立局部 X 窗口，以局部最大峰显示百分比强度。找不到 envelope 时退化为中心 m/z 周围窗口。

[`FragmentationView`](../src/features/prsm/FragmentationView.tsx) 不是普通质谱图：它把序列梯图、单同位素质量 stick plot 和 ppm error plot 放进共享质量轴，并用水平滚动代替 D3 zoom。

### BU 匹配详情

```text
BuMatchDetailPage
├─ fetchBuMatchXic → BuXicChart → BuInteractivePlot
├─ fetchBuMatchMs1 / fetchBuMatchMs2 → BuSpectrumChart
├─ matched ion selection → BuProductIonXicCard → BuProductIonXicChart
├─ useBuPfmbEvidence
│  ├─ PFMB slots / annotation / matrix
│  ├─ pfmbSpectrumOverlay → BuSpectrumChart.externalAnnotations
│  └─ BuPfmbAnnotationCard
└─ fetchBuMatchMobilitySlice → MzMobilityScatter
```

入口：[`BuMatchDetailPage.tsx`](../src/features/bu/pages/BuMatchDetailPage.tsx)。

[`BuSpectrumChart`](../src/features/bu/components/spectrum/BuSpectrumChart.tsx) 是当前 BU MS1/MS2 主谱图：

- 输入为 `BuSpectrumV1`，内部把 `mz[]`、`intensity[]`、`matched_ions[]` 合成峰模型。
- MS2 默认使用相对强度，MS1 可显示 precursor marker。
- live 注释来自 `BuMatchedIon`；PFMB 注释通过 `SpectrumExternalAnnotation[]` 叠加。
- `annotationMode` 明确控制 `live`、`external`、`both`。
- PFMB 只绘制已经映射到 raw peak 的注释，避免在实验谱上伪造峰。
- 匹配峰点击转换为稳定的产物离子选择。
- 峰标签由 [`spectrumLabelLayout.ts`](../src/features/bu/components/spectrum/spectrumLabelLayout.ts) 进行 top/all/none 模式和空间避让。

PFMB 当前方案不是一张独立谱图。路径是：

1. [`useBuPfmbEvidence.ts`](../src/features/bu/components/match-detail/useBuPfmbEvidence.ts) 取得 slot、annotation 和 matrix。
2. [`pfmbSpectrumOverlay.ts`](../src/features/bu/components/spectrum/pfmbSpectrumOverlay.ts) 把 PFMB neutral mass / charge 映射到 live raw MS2 peak。
3. 映射结果以 external annotation 传入 `BuSpectrumChart`。
4. 未映射注释保留在 PFMB 表格/质量信息中，但不画在 live 谱峰上。

因此 [`BuPfmbSpectrumChart.tsx`](../src/features/bu/components/spectrum/BuPfmbSpectrumChart.tsx) 当前无消费者，不能作为新功能的默认模板。

### 纯谱图数据集

```text
DatasetModeGate → SpectraOnlyPage
├─ fetchSpectraFullScanIndex
├─ ScanListPanel + scanRelations
├─ ChromatogramPanel → BuChromatogramChart
├─ AcquisitionContextPanel
└─ SpectrumPanel
   ├─ fetchSpectraSpectrum
   ├─ peakAnnotations
   ├─ DetectedPeaksTable
   ├─ SpectrumChart
   └─ SpectrumModal
```

[`SpectrumPanel`](../src/features/spectra-only/components/SpectrumPanel.tsx) 复用 TD `SpectrumChart`，而不是建立第三套谱图渲染器。MS2 可启用 top-5/10/20 峰标签、base peak 相对强度和峰点击选择；MS1/父扫描可显示 precursor 高亮。

[`peakAnnotations.ts`](../src/features/spectra-only/utils/peakAnnotations.ts) 是原始谱峰标注的纯函数模块，负责：

- 过滤和排序有效峰。
- base peak 与 top-N 选择。
- 相对强度计算。
- 最近 m/z 峰匹配。
- 标签、选中峰和表格行的统一结果。

[`scanRelations.ts`](../src/features/spectra-only/utils/scanRelations.ts) 负责 MS1/MS2 亲子扫描关系和前体峰匹配，不应把这部分逻辑写进 `SpectrumChart`。

## 2. 两套 Zoom 类型

当前存在两个结构相同但定义独立的 `Zoom`：

- TD/纯谱图：[`SpectrumChart.tsx`](../src/features/prsm/SpectrumChart.tsx)。
- BU：[`chartTheme.ts`](../src/features/bu/components/spectrum/chartTheme.ts)。

二者都是 `{ x: [number, number] | null; y: [number, number] | null }`，但不应假设它们永远可互换。Agent 修改共享逻辑前需检查实际 import 来源。

## 3. 注释来源不可混淆

| 来源 | 类型/模块 | 展示原则 |
|---|---|---|
| TD TopPIC/TopFD | `MatchedIon`、`MsPeakRow`、`RawEnvelope` | 原始谱、去卷积匹配和 envelope 分层展示 |
| BU live mzML | `BuMatchedIon` | 由 live MS2 匹配产生，使用 b/y 系列颜色 |
| BU PFMB | `SpectrumExternalAnnotation` | 必须先映射到 raw peak 才能叠加到 live 谱图 |
| 纯谱图 raw peak | `PeakAnnotation` | top-N m/z 标签，不宣称离子类型 |

相关类型分别位于 [`parse.ts`](../src/features/prsm/parse.ts)、[`types.ts`](../src/features/bu/types.ts)、[`spectrumAnnotation.ts`](../src/features/bu/components/spectrum/spectrumAnnotation.ts) 和 [`peakAnnotations.ts`](../src/features/spectra-only/utils/peakAnnotations.ts)。
