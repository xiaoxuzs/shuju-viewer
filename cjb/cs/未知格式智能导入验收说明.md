# 未知格式智能导入验收说明

## 目标

MaxQuant 仅作为输入样本，正式执行路径必须使用 `app.declarative_ingest` 的通用 reader、字段映射、关系校验和 ZP 语义扩展；不得依赖 `maxquant_mzml_v1`。

## 完整样本

```powershell
$env:VIEWER_MAXQUANT_DATASET_ROOT = '<MaxQuant single-sample 目录>'
back\.venv\Scripts\python.exe cs\MaxQuant通用机制验收.py `
  --output .tmp\MaxQuant通用机制验收\candidate.zp
```

通过条件：

- `.zp` deep validation 通过。
- 35 条 PSM、32 条肽段、33 条蛋白、32 个蛋白组、1 条实际修饰、35 条 PSM 定量被回读。
- 35 条 PSM 均通过声明式 exact scan join 关联真实 MS2。
- 未使用字段全部在 `unmapped_fields` 中登记并仍保存在 `source_fields`，没有静默丢弃。
- 4 个 FASTA 中不存在的污染库 accession 保持 sequence 缺失，能力报告给出补充 FASTA 的建议。

## 降级样本

- 删除或不声明 FASTA：PSM、肽段、蛋白 accession、谱图继续可用；sequence coverage 禁用。
- 不声明 mzML：结果表实体继续导入；谱图、XIC、fragment annotation 禁用。
- 定量单元格为空与数值 `0` 必须分别保存为 `null` 与 `0.0`。
- 未声明 fragment 数据时，能力报告必须为 `MISSING`，不得由模型补造。

## 通用性检查

后端单测另使用任意文件名和非 MaxQuant 列名的合成表。只有字段语义计划决定导入结果，软件名、目录名和固定文件名不得参与生产执行分支。

## 真实双 Agent schema v3 验收（2026-09-04）

本轮真实调用没有向模型暴露 `maxquant_mzml_v1`：

```powershell
back\.venv\Scripts\python.exe cs\Kimi研究Agent真实验收.py `
  --source <MaxQuant single-sample 目录> `
  --output .tmp\双Agent通用验收\Agent1.json `
  --user-message 'confirm unit:Retention time=minute' `
  --user-message 'confirm acquisition_mode=dda'

back\.venv\Scripts\python.exe cs\DeepSeek实施Agent真实验收.py `
  --blueprint .tmp\双Agent通用验收\Agent1.json `
  --output .tmp\双Agent通用验收\Agent2.json `
  --user-message 'confirm unit:Retention time=minute' `
  --user-message 'confirm acquisition_mode=dda'

back\.venv\Scripts\python.exe cs\DeepSeek实施Agent真实验收.py `
  --blueprint .tmp\双Agent通用验收\Agent1.json `
  --candidate .tmp\双Agent通用验收\Agent2.json `
  --execute-root .tmp\双Agent通用验收\execution `
  --user-message 'confirm unit:Retention time=minute' `
  --user-message 'confirm acquisition_mode=dda'
```

真实结果：

- Agent 1 从 `AUTO` 判定为 `BOTTOM_UP`，完成 10/10 文件通用检查以及 mzML、FASTA 科学摘要。
- Agent 2 输出 `schema_version=3`、`viewer_declarative_bottom_up_v1` 计划；22 个 canonical mappings，91 个字段显式列入 `unmapped_fields`。
- 同一份模型计划实际写入并 deep-validate ZP：7,534 spectra、1 chromatogram、35 PSM、32 peptides、33 proteins、32 protein groups、1 modification、35 quantification；35/35 spectrum links 为 `DIRECT`。
- 29 个 protein sequence 为 `DIRECT`，4 个为 `MISSING`；coverage 为 `PARTIAL`，fragment annotation 为 `DISABLED`，补充输入建议进入能力报告。
- 模型曾提出未注册 target、错误列表 shape 和无逐文件证据的 disposition，均被 deterministic preflight 拒绝；修复来自通用 target/view/evidence 合同，没有增加 MaxQuant 分支。

真实复核记录需区分“执行器结果”与“整条审批链”：一个 Agent 2 候选实际生成了上述正确数据，但 Agent 1 因 `Modifications` delimiter 与 Blueprint 不一致而拒绝发布；rework 候选修正该项后，又被执行器发现 `leading_accession` 的多值标量冲突。该冲突现已前移到 deterministic preflight。因而本轮证明了通用研究、计划生成、真实执行和拒绝门禁均有效，但不把尚未同时通过 Agent 1 review 与执行验证的候选记录成已发布成功。
