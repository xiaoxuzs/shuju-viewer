# 性能测验约定（指纹阶段）

## 适用范围与目标

修改影响指纹或根路径性能时运行本基准；纯文档和无关功能修改不要求执行。正确性用 `back/tests/` 的小 fixture 验证排序、排除规则及 size/mtime 变化；CI 可在配置真实基准数据的 job 中运行性能验收。

- 基准数据集：`MZ20160222DS_histone49_html`。
- 调用 `resolve_ingest_root` 解析用户选择的目录后，仅计量生产指纹 API 的墙钟耗时；根路径解析不计入指纹耗时。
- 至少 3 次测量取中位数，目标 ≤ 0.5 秒。超标时记录结果和 profiling 结论，不通过调高阈值宣称达标；缺少数据或依赖时说明未验证。
- 元数据格式、排除项及旧 demo 差异见 [模块边界与实施顺序](模块边界与实施顺序.md)，测验脚本调用公开 API，不复制算法。

## 运行

优先将 `VIEWER_BENCH_DATASET_ROOT` 设为实际基准目录，避免为本机路径改动脚本；也可使用脚本内已有的 `BENCHMARK_DATASET_PATH`。环境变量优先，外层嵌套目录会先解析为 ingest 根目录。

在本项目根目录、使用具备后端依赖的 Python 环境执行：

```powershell
python -X utf8 cs\指纹性能测验.py
# 或使用 back 的 uv 环境：
uv run --directory back python -X utf8 ..\cs\指纹性能测验.py
```

入口为 [指纹性能测验.py](指纹性能测验.py)。保留 `RUN_COUNT = 3`、`TIME_BUDGET_SECONDS = 0.5` 作为验收配置；脚本允许配置阈值不表示有权放宽业务标准。超过阈值退出码为 1。

记录解析后的根路径、`file_count`、指纹 hex、每次耗时及中位数。数据规模和机器环境需可辨认，历史测试记录不能替代本次结果。
