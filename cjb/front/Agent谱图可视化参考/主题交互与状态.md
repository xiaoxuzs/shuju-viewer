# 主题、交互与状态

## 1. 颜色来源

全局图表颜色入口是 [`CHART_COLORS`](../src/features/theme/chartColors.ts)：

- `grid`、`axis`、`text`。
- `unmatched`、`selection` 及 selection 前景/弱化色。
- 12 个离散 series 色。
- 6 个 heat 色。

CSS token 定义在 [`globals.css`](../src/styles/globals.css)，同时覆盖亮色和暗色主题。BU 二次语义映射位于 [`chartTheme.ts`](../src/features/bu/components/spectrum/chartTheme.ts)，包括 b/y、TIC/BPC、同位素、RT window、apex 和标准高度。

PFMB 系列颜色集中在 [`pfmbSeries.ts`](../src/features/bu/components/match-detail/pfmbSeries.ts)，产物离子比较颜色集中在 [`productIonColors.ts`](../src/features/bu/components/match-detail/productIonColors.ts)。

## 2. 缩放和大图

| 渲染器 | X/Y 缩放 | 大图 | 状态所有者 |
|---|---|---|---|
| `SpectrumChart` | D3 brush X，支持 Y | `SpectrumModal` | 组件内部或父级受控 `Zoom` |
| `BuSpectrumChart` | D3 brush X，支持 Y | `BuChartModal` | 组件内部或父级受控 `Zoom` |
| `BuInteractivePlot` | D3 brush X，支持 Y | 调用者决定 | 组件内部或父级受控 `Zoom` |
| `FragmentationView` | 无 brush | 无 | px/Da + 原生横向滚动 |
| `ThreeLcmsScene` | OrbitControls | 无 | Three.js controls |

modal 打开时如果需要保留缩放，父组件必须使用受控 zoom。不要依靠组件卸载前的内部 state。

## 3. Tooltip 和点击

- D3 谱图/曲线使用 React state 显示 tooltip，并用 bisector 查找最近峰/点。
- React SVG 小图多使用原生 `<title>`。
- `BuXicChart` 点击返回 RT；联动规则由页面处理。
- `BuSpectrumChart` 点击 matched ion；选择规则由 `productIonSelection.ts` 处理。
- PFMB heatmap 点击 cell/slot；annotation card 处理 RT、slot 和高亮。
- 纯谱图 `SpectrumChart` 点击 raw peak；`SpectrumPanel` 统一更新标签和表格选择。

图形组件只上报最小选择数据，不应自行触发跨证据 API 请求。

## 4. 首帧与页面切换

页面切换系统位于 [`features/page-transition`](../src/features/page-transition/)。关键约定：

- D3/Three 渲染器完成第一帧后调用 `onFirstRender`。
- 如果没有数据、请求失败或渲染失败，容器也必须把 ready/error 信号向上传递，避免遮罩永久存在。
- [`useTransitionSignal`](../src/features/page-transition/pageTransitionContext.ts) 按 run/scan key 建立一次性完成信号。
- `SpectraOnlyPage` 同时等待 scan metadata、chromatogram 和需要显示的 spectrum。

相关回归：[`page-transition.spec.ts`](../tests/page-transition.spec.ts)。

## 5. 图表状态

[`PlotStatus`](../src/components/common/plot-status.tsx) 的当前种类包括：

- `loading`
- `empty`
- `error`
- `derived_missing`
- `derived_stale`
- `unsupported`
- `not_found`

[`ChartRenderBoundary`](../src/components/common/chart-render-boundary.tsx) 捕获 React render 阶段异常。D3 effect 或 Three.js renderer 的命令式异常仍需组件自行捕获并调用 error callback。

状态应尽量局部化：例如 product XIC 请求失败只影响 product XIC card，不应隐藏 live spectrum。

## 6. 无障碍标签

当前直接渲染器的关键 `role/img` 或 `aria-label`：

- RT-m/z：`RT by precursor m/z heatmap`
- DIA：`DIA isolation windows`
- mobility：`m/z by ion mobility`
- PFMB：`Fragment Match slot RT by fragment intensity heatmap`
- PFMB quality：`Fragment Match matched peaks per RT slot`
- BU spectrum：使用动态 `title`
- BU curve：`${xLabel} versus ${yLabel}`

测试依赖其中一部分名称。Agent 修改可访问名称时必须同步 Playwright 定位器。

## 7. 性能保护

- `SpectrumChart` 对过密未匹配峰按像素桶 max-pooling，匹配峰永不丢弃。
- `MzMobilityScatter` 最多约 4500 个 SVG 点。
- PFMB heatmap 默认只显示前 20 行，可展开。
- 纯谱图 scan index 以 2000 条分页并行聚合。
- product XIC 使用批量 POST，避免 N+1。
- Three.js cleanup 必须释放 controls、geometry/material、renderer 和 RAF。

新增可视化前先检查这些保护是否仍适用，不要为了“统一”删除它们。
