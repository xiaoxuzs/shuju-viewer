# 遗留与未启用组件

## 1. `features/bu-viewer` 是历史副本

目录：[`features/bu-viewer`](../src/features/bu-viewer/)。

调查结果：

- `features/bu`：67 个 TypeScript/TSX 文件。
- `features/bu-viewer`：67 个 TypeScript/TSX 文件。
- `bu-viewer` 中有 47 个文件互相引用 `@/features/bu-viewer/...`。
- `bu-viewer` 目录外对它的引用为 0。
- 当前 [`App.tsx`](../src/App.tsx) 直接引用 `@/features/bu/...`。
- `bu` 最近一次相关提交为 2026-08-26；`bu-viewer` 最近一次相关提交为 2026-08-02。
- 对齐 import 前缀后，两套目录仍有 65 个同名文件内容不同。

结论：`bu-viewer` 不是组件库，也不是当前完整实现。Agent 不得以其代码作为新增功能的起点；如需历史对比，应显式说明“历史副本”。

## 2. 当前业务区的不可达文件

从 [`main.tsx`](../src/main.tsx) 沿静态 import 追踪，四个当前可视化区只有以下 3 个不可达文件。

### `BuPfmbSpectrumChart.tsx`

源码：[`BuPfmbSpectrumChart.tsx`](../src/features/bu/components/spectrum/BuPfmbSpectrumChart.tsx)。

- 它是一个独立 PFMB D3 spectrum renderer。
- 当前没有任何 import 消费者。
- 当前产品设计把 PFMB annotation 映射并叠加到 live [`BuSpectrumChart`](../src/features/bu/components/spectrum/BuSpectrumChart.tsx)。
- [`bu-pfmb-visuals.spec.ts`](../tests/bu-pfmb-visuals.spec.ts) 明确验证“不再展示 standalone PFMB spectrum”。

因此只登记，不推荐复用。

### `chartUtils.ts`

源码：[`chartUtils.ts`](../src/features/bu/components/spectrum/chartUtils.ts)。

包含 `extent`、`scale`、`compactNumber`，当前没有消费者。不要为了使用它而改写 D3 组件。

### `BuComingSoonPage.tsx`

源码：[`BuComingSoonPage.tsx`](../src/features/bu/pages/BuComingSoonPage.tsx)。当前没有路由，不属于谱图组件。

## 3. 构建产物不是参考源码

目录：[`dist`](../dist/)。

`dist/assets/*.js` 是 Vite 打包结果，符号已合并/压缩。Agent 查组件、Props 或数据契约时不得引用 `dist`；构建产物也不能用于判断某个未导入源码是否“当前使用”。

## 4. 根目录截图是历史证据

`front` 根目录当前有 20 张 `pr*.png`/`debug*.png`，覆盖 BU overview、XIC、MS1/MS2、coverage、DIA、QC 等历史界面。

它们没有被 [`front/src`](../src/) 引用。使用规则：

- 可以辅助理解曾经的视觉目标。
- 不能代替当前路由、组件引用或测试。
- 文件名中的 PR 编号不等于当前版本号。
- `debug-pr6.png` 只视为调试资产。

## 5. 未启用不等于应删除

本参考目录只报告状态，不删除或重构历史代码。是否删除 `bu-viewer` 或未启用文件属于独立任务，需要单独评估并获得确认。
