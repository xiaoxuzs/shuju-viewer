Universal Viewer 数据库结构

目标库为 PostgreSQL。权威 DDL 与注释见仓库内 docs/universal_schema.sql；后端读路径使用 SQLAlchemy text() 直连这些表，无 ORM 实体层。

总览

  • 核心域表（7）：datasets → runs；proteins；peptides / proteoforms；identification_matches（PSM/PrSM 统一）；protein_relation_mapping（蛋白 ↔ 肽段/形态）。
  • 任务表（1）：import_jobs — ZIP 导入后台任务状态与进度（与 schema 文件同源；旧库可由启动逻辑补建）。
  • 无独立表：cutoff 由 identification_matches.extra_metadata->>'source_cutoff' 与 API 层常量合成，见 docs/architecture.md。
启动时迁移（非 SQL 文件内首次建表）：back/app/services/import_jobs.py 会在连接可用时执行 ensure_dataset_zip_fingerprint_schema()（datasets.source_zip_sha256 + 部分唯一索引）与 ensure_runs_metadata_schema()（runs.run_metadata），以便与旧库兼容。

实体关系示意图

内嵌 SVG：左右泳道区分「运行/鉴定」与「蛋白/映射」；中央说明框写清 entity_type 与 entity_id 如何二选一指向实体表；四条虚线使用不同高度，减少交叉。实线 = DDL 外键。

表：datasets

datasets数据集总入口：项目/批次；URL 用 slug；能力用 capabilities JSON。
dataset_idBIGSERIAL PK数据集唯一内部 ID。
dataset_nameVARCHAR(255) NOT NULL展示名称。
slugVARCHAR(160) NOT NULL UNIQUE短标识，URL 与查询。
analysis_modeVARCHAR(20)BOTTOM_UP | TOP_DOWN（CHECK）。
source_softwareVARCHAR(100)来源软件名。
source_rootTEXT数据集根目录路径。
statusVARCHAR(20) DEFAULT IMPORTEDIMPORTED | PARSING | READY | ERROR。
descriptionTEXT说明。
capabilitiesJSONB能力声明（MS1/MS2/PrSM 等）。
extra_metadataJSONB扩展元数据。
created_atTIMESTAMPTZ创建时间。
source_zip_sha256CHAR(64) NULL导入 ZIP 的 SHA-256；部分唯一索引 uq_datasets_source_zip_sha256（WHERE NOT NULL）。

表：runs

runs实验文件 / 运行；FK dataset_id → datasets ON DELETE CASCADE。
run_idBIGSERIAL PK运行 ID。
dataset_idBIGINT FK所属数据集。
file_pathTEXT服务器上文件路径。
file_nameVARCHAR(255)展示用文件名。
analysis_modeVARCHAR(20)BOTTOM_UP | TOP_DOWN。
softwareVARCHAR(100)来源软件。
statusVARCHAR(20)IMPORTED | PARSING | READY | ERROR。
instrument_metadataJSONB仪器与采集参数。
sample_metadataJSONB样本信息。
run_metadataJSONB运行级扩展（如 mzML 映射；启动迁移可补列）。
created_atTIMESTAMPTZ创建时间。

表：proteins

proteinsBottom-up / Top-down 共用蛋白根节点；UNIQUE (dataset_id, accession, is_decoy)。
protein_idBIGSERIAL PK
dataset_idBIGINT FK
accessionVARCHAR(255)如 UniProt。
gene_nameVARCHAR(255)
descriptionTEXT
base_sequenceTEXT理论序列。
is_decoyBOOLEAN DEFAULT false
extra_metadataJSONB

表：peptides

peptidesBottom-up 肽段；UNIQUE (dataset_id, sequence)。
peptide_idBIGSERIAL PK
dataset_idBIGINT FK
sequenceVARCHAR(1000)无修饰纯序列。
theoretical_massDOUBLE PRECISION
lengthINTEGER
missed_cleavagesSMALLINT
extra_metadataJSONB

表：proteoforms

proteoformsTop-down 蛋白形态（PTM 等）。
proteoform_idBIGSERIAL PK
dataset_idBIGINT FK
modificationsJSONB default []PTM 列表。
start_res / end_resINTEGER在基础蛋白上的区间。
theoretical_massDOUBLE PRECISION
extra_metadataJSONB

表：identification_matches

identification_matches统一 PSM/PrSM：entity_type ∈ PEPTIDE | PROTEOFORM，entity_id 多态指向对应表。
match_idBIGSERIAL PK
dataset_idBIGINT FK
run_idBIGINT FK → runs定位原始文件。
scan_numberINTEGER与 run 联立定位谱图。
spectrum_native_idVARCHAR(255)可选原生谱 ID。
retention_timeDOUBLE PRECISION
ms_levelSMALLINT DEFAULT 2
entity_type / entity_idVARCHAR(30) / BIGINT多态关联。
modified_sequenceTEXT展示用带修饰序列。
experimental_mass, precursor_mz, precursor_charge数值母离子相关。
intensityDOUBLE PRECISION
score, e_value, q_value, pepDOUBLE PRECISION统计与打分。
is_decoy_matchBOOLEAN
search_engineVARCHAR(100)
detail_pathTEXT详情文件路径。
detail_cacheJSONB解析缓存。
extra_metadataJSONB含 source_cutoff 等扩展。

表：protein_relation_mapping

protein_relation_mapping蛋白 ↔ 肽段/形态多对多；entity_type ∈ PEPTIDE | PROTEOFORM。
mapping_idBIGSERIAL PK
dataset_idBIGINT FK
protein_idBIGINT FK → proteins
entity_type / entity_idVARCHAR(30) / BIGINT指向 peptides 或 proteoforms。
start_position / end_positionINTEGER在基础蛋白序列上区间。
is_uniqueBOOLEAN DEFAULT false
extra_metadataJSONB

表：import_jobs

import_jobsZIP 导入异步任务；job_id UUID；status ∈ queued | running | success | failed。
job_idUUID PK前端轮询凭据。
statusVARCHAR(20)queued / running / success / failed。
stageVARCHAR(40)阶段代码（如 extract、matches）。
stage_label / stage_detailTEXT展示标签与细节。
message / errorTEXT消息与错误。
progressDOUBLE 0..100进度百分比。
dataset_slug / dataset_nameVARCHAR成功后可跳转 slug。
descriptionTEXT导入时描述。
source_zip_nameTEXT上传 zip 文件名。
created_at / updated_atTIMESTAMPTZTTL 清理用 updated_at。
