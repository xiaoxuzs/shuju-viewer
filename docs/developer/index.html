实现状态提醒

  • 这些文档反映当前源码状态，不是产品能力承诺。
  • 当前未找到 MGF 导入实现。
  • 当前未找到 ZIP 上传入口实现，旧文档中可能存在历史描述。
  • 当前 RAW 路径主要确认 Thermo RAW 转换，不应写成所有厂商 RAW 都支持。
  • RAW 不直接读取，当前流程是先转换为 uncompressed indexed mzML 再读取。
  • .viewer-derived 是磁盘派生目录，不是数据库表。
  • PFMB annotation 和 live mzML MS2 不是同一种数据源。
  • 当前未找到 Docker 和生产部署说明。
  • 当前未找到统一错误码注册表。
