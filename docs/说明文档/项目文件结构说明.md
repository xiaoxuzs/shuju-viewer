## 已确认 RAW/mzML 与 spectra-only 能力

本节仅记录当前源码、当前 PostgreSQL 只读查询、当前本机真实 dataset/run、磁盘派生文件和本轮测试已经确认的内容；未在源码或数据库中确认的能力不写作已实现能力。

### RAWonly 和 mzMLonly 导入能力

- 纯 `.mzML` 目录导入由 `back/app/ingest/mzml_only_adapter.py` 提供，`import_mzml_only_dataset()` 会为每个 mzML 文件写入 `datasets` 与 `runs` 记录，并把 `run_metadata.raw_format` 记录为 `mzml`。
- Thermo `.raw` 目录导入由 `back/app/raw_conversion/` 与 `back/app/services/import_jobs.py` 编排支持；`import_jobs` 在需要 RAW 转换时调用 `convert_raw_files_for_import()`，转换完成后再把 converted mzML 交给 mzML-only 导入链路。
- `back/app/raw_conversion/tool_discovery.py` 中 `resolve_thermo_raw_file_parser_exe()` 支持两类 `ThermoRawFileParser.exe` 发现方式：显式配置的 `THERMO_RAW_FILE_PARSER_EXE`，以及仓库根目录下的 `ThermoRawFileParser1.4.5/ThermoRawFileParser.exe` 本地工具路径。
- `back/app/raw_conversion/thermo_raw_file_parser.py` 的 `build_thermo_raw_file_parser_command()` 当前生成的转换命令参数为 `-i=<raw_path>`、`-o=<output_dir>`、`-f=2`、`-m=0`；本轮真实 run metadata 中也记录了同样参数。
- `validate_converted_mzml()` 要求 converted mzML 是未压缩 mzML，并包含 `indexListOffset`；缺少 embedded index 的文件会返回 `raw_conversion_output_invalid`，不能进入后续 indexed reader 流程。
- same-stem 已有 mzML 由 `validate_existing_same_stem_mzml()` 校验；只有通过 indexed 校验的 same-stem mzML 才会以 `skipped_existing_mzml` 状态复用。

### spectra-only 页面当前能力

- `front/src/features/spectra-only/components/RunSummaryCards.tsx` 展示 `Total scans`、`MS1 scans`、`MS2 scans`、`Other scans`、`RT range`、`Scan range`、`Max TIC`、`Max BPC`、`MS2 fraction`、`Precursor-linked MS2`。
- `front/src/features/spectra-only/components/ScanListPanel.tsx` 支持 `All`、`MS1`、`MS2` 筛选，本地分页，每页 `16` 条，`Previous`、`Next`、`Go to page`、scan number 搜索，并在页面左侧以 sticky 紧凑选择器呈现。
- `front/src/features/spectra-only/utils/scanRelations.ts` 根据完整 scan index 建立 MS1/MS2 采集层关系：选中 MS2 时可找到 parent MS1，parent MS1 下可列出 child MS2 scans，child MS2 点击后切换 selected scan。
- `front/src/features/spectra-only/pages/SpectraOnlyPage.tsx` 在选中 MS2 时显示 `Parent MS1 Spectrum` 与 `Selected MS2 Spectrum`；`SpectrumPanel.tsx` 在 parent MS1 中以 precursor m/z 近邻峰高亮 precursor peak。
- `front/src/features/spectra-only/utils/peakAnnotations.ts` 当前 MS2 原始峰标记模式为 `Off`、`Top 5`、`Top 10`、`Top 20`，默认值为 `Top 10`，并识别 base peak、selected peak 和相对强度。
- `front/src/features/spectra-only/components/DetectedPeaksTable.tsx` 展示 detected peaks 表格，列包含 `m/z`、`Intensity`、`Relative intensity`、`Type`；`SpectrumPanel.tsx` 让谱图 peak 点击与表格行选择共享 selected peak 状态。
- `front/src/features/prsm/SpectrumChart.tsx` 提供 `yHeadroomRatio`；spectra-only 的 selected MS2 spectrum 使用 `SPECTRA_ONLY_MS2_Y_HEADROOM_RATIO = 0.12` 给最高峰上方留白，该参数只影响显示比例，不改写真实 intensity 数组。

### 数据库与文件存储模型

- 当前后端数据库配置和只读连接确认数据库类型为 PostgreSQL；本轮只读查询连接到当前本机数据库 `Universal_Viewer`。
- 数据库不存 RAW 文件本体，也不存 converted mzML 文件本体；`datasets` 保存 dataset 级状态、路径、capabilities、extra metadata，`runs` 保存 run 级 `file_path`、`file_name`、`run_metadata`。
- RAW 文件路径记录在 `runs.run_metadata.raw_path`；converted mzML 路径记录在 `runs.run_metadata.mzml_file_path`，并同步体现在 `runs.file_path`。
- RAW 转换对象记录在 `runs.run_metadata.raw_conversion`，字段包含 `status`、`command`、`converter_name`、`converter_version`、`stdout_log_path`、`stderr_log_path`、`started_at`、`finished_at`、`error_message`。
- `back/app/services/mzml_scan_index.py` 将 scan index 写入磁盘派生文件 `.viewer-derived/mzml-scan-index/<dataset_id>/<run_id>/scan-index-v1.npz` 与 `scan-index-v1.json`，不写入数据库。
- `back/app/bu/services/chromatogram_summary.py` 将 chromatogram summary 写入磁盘派生文件 `.viewer-derived/bu-chromatograms/<dataset_id>/<run_id>/summary-v1.npz` 与 `summary-v1.json`，不写入数据库。
- 谱图查看时，`back/app/api/v1/mzml_spectra.py` 先通过数据库定位 `dataset_id`、`run_id`、`runs.file_path`/`run_metadata.mzml_file_path`，再由 `back/app/services/mzml_scan_reader.py` 从磁盘 indexed mzML 按 scan number 读取 mz 与 intensity。

### spectra-only 边界说明

- spectra-only 是原始谱图查看模式，不是鉴定结果查看模式。
- RAW 和 mzML 只提供原始谱图及采集元数据；RAWonly 不显示 protein、peptide、PSM、fragment annotation、sequence coverage 属于当前数据形态下的正常结果。
- 当前 MS2 标记只覆盖原始检测峰、TopN、base peak、selected peak；不是 b ion、y ion、peptide、protein 或 fragment match 标注。
- 如需显示蛋白、肽段、PSM、fragment annotation 或 sequence coverage，需要导入 DIA-NN、TopPIC、pFind、MaxQuant、MSFragger 等鉴定结果。
- `.zp` 设计当前不属于本节已确认实现范围，未写作已完成功能。
