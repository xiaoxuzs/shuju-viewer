1 总览

核心业务表（6 张）

表名用途读/写
datasets数据集总入口，项目/批次级别读 + 写
runs实验文件 / 原始谱图文件读 + 写
proteins蛋白质生物学根节点（BU/TD 共用）读 + 写
proteoformsTop-down 蛋白形态（PTM、截短等）读 + 写
identification_matches统一 PSM/PrSM 匹配表（核心）读 + 写
protein_relation_mapping蛋白 ↔ 形态 多对多映射读 + 写

任务管理表（1 张）

表名用途
import_jobsZIP 导入异步任务状态与进度

DDL 中存在但代码未使用

表名状态说明
peptides未使用为 BOTTOM_UP 模式预留，当前只有 TOP_DOWN 适配器

关键架构特点

  • 无 cutoff 表 — source_cutoff（"prsm" / "proteoform"）存在 extra_metadata JSON 中，注册表为内存常量
  • 无谱图数据表 — 谱图峰数据不入库，来自磁盘 .js 文件或内存 mzML Store
  • 业务 ID 存 JSON — TopPIC 的 source_prsm_id、source_sequence_id 等存于 extra_metadata，查询时 jsonb_extract_path_text() 提取
  • 详情文件懒加载 — detail_path 存文件路径，API 按需读取

8 SQL 查询模式

读取路径（API 层）

场景主查询表关键 SQL 模式
数据集列表datasetsSELECT ... ORDER BY dataset_id
数据集详情datasetsSELECT ... WHERE slug = :slug
Cutoff 统计im + prmCTE 提取 source_cutoff，LEFT JOIN 计数
蛋白列表proteinsEXISTS (prm JOIN im WHERE source_cutoff)
蛋白形态列表proteoforms可选 JOIN prm 按蛋白过滤
PrSM 列表im LEFT JOIN proteoforms按 source_cutoff 和 source_prsm_id 过滤
PrSM 详情im + proteoforms加 dataset_id + run_id 精确定位
mzML 谱图runsSELECT ... WHERE run_id = :id 获取 run_metadata

写入路径（导入适配器）

阶段操作
初始化INSERT INTO datasets → INSERT INTO runs
写蛋白INSERT INTO proteins（按 source_sequence_id 内存去重）
写形态INSERT INTO proteoforms
写映射INSERT INTO protein_relation_mapping（内存去重）
写匹配INSERT INTO identification_matches（按 cutoff_kind + source_prsm_id 去重）
补填UPDATE identification_matches 批量补 run_id、scan_number 等
完成UPDATE datasets/runs SET status = 'READY'

运行时写入

场景操作
首次请求 mzML 谱图UPDATE runs SET run_metadata = ... 回填 mzML 路径
首次请求谱图UPDATE datasets SET capabilities = ... 设置 spectra_source
目录重命名后UPDATE identification_matches SET detail_path = REPLACE(...)
清理无用 runDELETE FROM runs WHERE NOT EXISTS (identification_matches ...)
删除数据集DELETE FROM datasets WHERE slug = :slug（CASCADE 自动清理子表）

9 设计决策

  • 多态关联 — identification_matches 和 protein_relation_mapping 使用 entity_type + entity_id 多态模式，数据库层不强制外键，由应用层保证一致性
  • JSONB 扩展字段 — extra_metadata 存储来源软件特有的字段和业务 ID，避免频繁 DDL 变更
  • 详情文件懒加载 — detail_path 存文件路径，API 按需读取解析，避免大 JSON 常驻数据库
  • 谱图不入库 — 谱图峰数据量大，存于磁盘文件，通过内存缓存（MzmlStore / spectrum_cache）加速访问
